## 📌 Overview
This project aims to analyze and quantify **Student Social Media Addiction** using advanced **Natural Language Processing (NLP)** and **Large Language Models (LLMs)**. By leveraging linguistic patterns, textual data, and machine learning models, this repository provides a framework to compute addiction scores and understand social media behavior among students.

---

## 🚀 Key Features
- **Data Preprocessing & Cleaning:** Text normalization, tokenization, stop-word removal, and sentiment analysis pipeline.
- **NLP Feature Extraction:** Extraction of syntactic, semantic, and psychological markers from student textual inputs.
- **LLM Integration:** Fine-tuning / prompting Large Language Models for context-aware classification and scoring.
- **Stable Feature Pyramid Network / Model Pipeline:** Implementation of stable feature combination and evaluation techniques for scoring social media addiction.
